# APEX backend — Express API

```bash
cp .env.example .env
pnpm install
pnpm dev
```

Useful scripts:

- `pnpm seed` — curated seed bikes/articles
- `pnpm seed:admin` — demo admin user
- `pnpm seed:sync` — pull catalog from API Ninjas
- `pnpm seed:images` — backfill remote photos

Health check: [http://localhost:4000/api/health](http://localhost:4000/api/health)
